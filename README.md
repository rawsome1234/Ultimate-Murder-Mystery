# Ultimate Murder Mystery
Ultimate Murder Mystery is a behavior pack for a multiplayer social deduction game. This pack adds a multitude of custom features, roles, features for map makers, and more!

## Features
The following is a mostly complete list of features:
- 50 Custom Roles across 4 alignments
    - Roles have custom abilities
- Role Guessing
- Ghost Bodies
- 30 Modifiers (Secondary Roles)
- A Custom Music System
    - 2 Custom Tracks
- Role Draft
- Role Descriptions and Help for Players
- Game Log
- Chat Hiding/Usage
    - A Murderer Chat
- Death Management
- Win Condition Handling
- Rule Presets
- Role/Modifier Enabled Randomizer
- Role Weights
- AFK Support
- Game/Session Stats
- Knockout Mode
- Opening-Game Protection
- Prevents Players from interacting with some blocks
- Nametag Hiding
- In-game About Page
- Lots and Lots and Lots of configuration

## Installation
Download the latest .mcpack files from the latest release. While Minecraft Bedrock is closed, open them to install them. There is a setup.md you can view to see how to setup the world and game.

## How to Play Murder Mystery
There is a how_to_play.md file included in the pack that you can view in github by clicking it in the files.

## Future Updates
This pack is considered feature complete and I am moving on from the project. The pack will get maintenance updates when Minecraft Bedrock gets a new update to stay usable, and may occassionally get bug fixes or balance changes for the default settings. There are no plans to bring this to Minecraft Java.
